# Ad Set Name Examples That Answer Real Questions

Here's an ad set name example you can copy today: `2026-10-12_Broad-US_LC_C14-SleepFix`. That's launch date, audience, bid type, and the concept under test, in that order.

Most naming guides stop at the pattern and skip why each field is there. **A field earns its place in a name only when you can say which question it answers.** If you can't, it's clutter; clutter is how a naming convention dies by week three.

Below are patterns for all three levels, plus the two places experienced buyers disagree.

## What should an ad set name include?

An ad set name should record how and when you're buying, plus the concept if you run one concept per ad set.

We call the rule behind it **question-first naming: before a field goes into a name, you write down the report it will let you pull.** Here's how the common fields pass the test:

| Field | The question it answers |
|---|---|
| Launch date | Which weekly batch is this, and does it join to my tracker? |
| Audience | Is broad beating my stacked audiences? |
| Bid type | Is cost cap earning its keep against lowest cost? |
| Concept | Which idea won, across every ad set it ran in? |
| Creator | Who's worth rebooking? |
| Format | Are statics carrying more spend than video? |
| Destination | Product page or advertorial? |

Fields like "final" or "NEW" fail.

## Campaign, ad set, and ad name examples

Experienced practitioners agree on the job of each level: the campaign holds structure, the ad set holds the buying decision, and the ad holds everything about the creative.

**Campaign names** carry type, objective, location, and offer:

```
PRO_Sales_US_20OFF
EXIST_Sales_US-CA_Bundle
```

**Ad set names** follow the table above:

```
2026-10-12_Broad-US_LC_C14-SleepFix
2026-10-12_Broad-US_CC_C15-Travel
```

**Ad names** come in a lean and a rich version:

```
Lean:  VID_UGC_SleepFix_NoMoreAlarm_PDP
Rich:  C14_VID_UGC_Kai_SleepFix_ProblemAware_H2_v3_W42_PDP
```

Use codes for closed lists like bid type and format, and words for open ones like concept and creator. Then publish the key.

## Split 1: how many fields should a name carry?

Experienced buyers split on this. One camp keeps names lean, about five fields per level, often in short codes. It wins for small teams where the media buyer types every name by hand.

The other camp runs 7 to 12 fields, adding things like awareness stage and test type, and it wins when a production pipeline sits behind the account and the name doubles as the brief ID. But practitioners in this camp report that more fields made their own teams use the convention less. Their templates shrank.

**Our take: if people type names by hand, cap the ad name at five to seven fields.** Go richer only when the name is generated from a sheet, a formula, or a tool, and every field passes the question test.

Say a team launches 40 ads a week and 1 in 10 hand-typed names drops or misspells a field (both hypothetical). That's 4 ads a week missing from every pivot table, or 52 a quarter. Your best ad could be one of them.

## Split 2: does the concept live in the ad set name or the ad name?

One camp puts the concept in the ad set name, because their testing system runs one concept per ad set, which stays clean as long as the ad stays where it was born. The other camp puts everything about the creative on the ad.

**Our take: put the concept in the ad name, always.** Add it to the ad set name too if you run one concept per ad set.

The reason is what happens to winners. Move a winning ad into a scaling campaign by its post ID and the ad set name stays behind, while the ad name travels with it into every export. Our guide to [Facebook ads testing](/blog/facebook-ads-testing) covers that move in full.

## What to stop doing

Experienced buyers agree on five habits to drop:

- **Default names:** "New ad" and stacked "- Copy - Copy" chains hide every pattern you'd want to find.
- **Mixed conventions:** one account gets one convention, whoever is launching.
- **Renaming live ads:** it breaks reporting continuity and the join to outside trackers. Apply the convention going forward and back-fill old names in a side table.
- **Funnel-stage labels:** TOF and BOF tags go stale the moment a campaign's job changes.
- **Expecting a lift:** naming fixes reporting, not performance.

A name is not proof of variety. Ten ads tagged as ten concepts can still look identical, so lay your top creatives side by side before trusting the labels.

Some practitioners also prefix any tactic they'll want to total later, such as ads run from a creator's page, so "have we really tested this?" becomes a filter with a spend figure. Our post on [whitelisting vs partnership ads](/blog/whitelisting-vs-partnership-ads) covers that tactic.
