# Ad Set Name Examples: 9 Patterns for Campaigns, Ad Sets, and Ads

Here's an ad set name example worth copying: `T042_sleep-launch_2026-10-14`. Test number, theme, launch date. It says nothing about creators or hooks. On purpose.

Most naming templates pile everything into the campaign and ad set names, which made sense back when one ad set held one concept from one creator.

**Today a test ad set holds 10 to 25 different ads, so the creative details have to live in the ad name, where a report can group them.**

Below: nine patterns across three levels, what each field buys you in analysis, and what breaks at volume. We built Draper Ads inside a paid social agency, by the media buyers who were doing the uploads.

## The rule behind every example: the pivot test

**The pivot test: a field belongs in a name only if you'll group results by it.** Nobody has ever pivoted a report on editor initials.

Creative strategist Dara Denney's process shows which fields pass. In [a creative audit](https://www.youtube.com/watch?v=cl_eM6edWUk&t=612s) she splits results by format, then by sub-format like us-vs-them, which only works if "the naming convention is really thorough." In [her creator system](https://www.youtube.com/watch?v=_VtpfVeB2Kc) she ranks results creator by creator to decide who to rebook.

Four fields pass the test. Concept, creator, format, angle.

## Campaign name examples

You'll filter campaigns by role, so keep them short.

### 1. Testing campaign

```
PUR_TEST_US_ABO
```

Objective, role, geo, budget type.

### 2. Scaling campaign

```
PUR_SCALE_US_ADVPLUS
```

Winners graduate here.

## Ad set name examples

Dara now [loads test ad sets](https://www.youtube.com/watch?v=MmXb2JmWDj8&t=121s) with 20 to 25 statics or 10 to 15 videos, mixing formats inside them on purpose. An ad set holding a green-screen video, a founder clip, and three statics can't be named after a format.

So name it after the test.

### 3. Creative test ad set

```
T042_sleep-launch_2026-10-14
```

Test ID, theme, and a year-month-day date so it sorts. The ID links the ad set to its brief in your [creative testing tracker](/blog/facebook-ads-testing).

### 4. Static batch ad set

```
T043_static-batch_2026-10-21
```

Dara puts [all statics into one ad set](https://www.youtube.com/watch?v=ZydGeio1DGQ&t=121s) once or twice a month instead of splitting them by message.

### 5. Scaling ad set

```
WIN_broad_US_2026-Q4
```

When a winner moves here, keep its ad name and strip the " - Copy" suffix Ads Manager adds. The ad name is the ad's ID card, so it should read the same in every ad set.

## Ad name examples

This is where the analysis happens. Same field order, every time:

```
concept_creator_format_angle_variant
```

### 6. Creator video

```
C017_sarah-k_yapper_sleep-anxiety_H1
```

Concept 17, creator Sarah K., a talk-to-camera yapper ad, the sleep-anxiety angle, hook 1.

### 7. Hook variant

```
C017_sarah-k_yapper_sleep-anxiety_H2
```

Only the last field changes. Dara runs [3 to 6 hook variants per video test](https://www.youtube.com/watch?v=I8tXqqfjIX4&t=551s), as big swings.

Group on everything but the hook to judge the concept, then on the hook alone to see which opening carried it.

### 8. Static with no creator

```
C021_brand_static-usvsthem_price_V1
```

Fill the creator slot with `brand` rather than leaving it empty, because a missing field shifts every later value one column left and your spreadsheet split breaks without warning.

### 9. Iteration on a winner

```
C017-I2_maria-l_greenscreen_sleep-anxiety_H1
```

Same concept, new creator, new visual. Dara stretches winners this way, often with a green-screen version. The `-I2` suffix keeps the family together when you filter on `C017`.

Compare that with what most accounts hold:

- **Bad:** `Sarah video NEW final v2 - Copy`
- **Good:** `C017_sarah-k_yapper_sleep-anxiety_H2`

One tells you who touched the file last. The other tells you why the ad worked.

## What breaks at 500 ads

Say a month brings 4 creators × 3 angles × 2 formats × 3 hooks: 72 new ads, 18 per creator. A teammate types `SarahK` instead of `sarah-k` on 6 of Sarah's 18.

Your creator report now shows two Sarahs.

A third of her ads sit in the wrong row, and your best creator looks average.

Four failures do the damage:

- **Free-text values:** keep a picklist of allowed values in a shared sheet.
- **Field drift:** add new fields at the end only, or last quarter's names stop parsing.
- **Names that flatter:** In Dara's [squint test](https://www.youtube.com/watch?v=U7T3_-NnHHg&t=122s), you lay out your top 10 to 20 ads and squint. If they look alike, you lack diversity "no matter what your naming convention says." Andromeda counts [visual difference, not labels](/blog/meta-andromeda-update).
- **Hand-typing:** 72 names typed into Ads Manager are 72 chances for a typo.

AI tagging now carries some load. Dara [notes](https://www.youtube.com/watch?v=KsVuc6RQ1L8&t=248s) that reporting used to run on naming conventions, and that Motion now adds AI tags. She's Motion's Chief Evangelist and says so.

Tags read what's on screen. Concept and test IDs live only in your planning doc; they still belong in the name.

## Put the convention in your file names

Draper Ads names every ad from its creative file, editable in one place before launch, so the convention lives where the creative is made: name the file `C017_sarah-k_yapper_sleep-anxiety_H2` in Google Drive and the ad inherits that name in every ad set you launch it to.

In Ads Manager, pasting names from a sheet works fine at 20 ads a week, but at 72 a month the typo math above starts to bite.

Name for the report you'll run in three months, not for the person uploading today.
