How I build AI for GTM at Dexory

Core. Engine. Project.

Before building anything, ask one question: which layer does this belong in? Fix it once, and everything downstream gets the fix.

01
Core
builds the timeline
  • Parse the documents
  • Pull the call transcripts
  • Dedupe the email threads
  • Find who is really on the deal
  • Keep CRM links intact
  • One clean timeline
02
Engine
stores the facts
  • A fact? Quote it
  • Inferred? Say so
  • New data? Track changes
  • Flag the answers it affects
  • Smart recalculation
03
Project
asks the question
  • Pipeline review scores deals
  • Handover lists commitments
  • Cohorts compare slipped deals
  • Own logic, own loop
Flags route back
The feedback loop
A rep flags something wrong. The flag gets routed back.
Engine error: the fact existed but wasn't found. Core error: it was missed building the timeline.
Bonus: every flag becomes a new eval.
